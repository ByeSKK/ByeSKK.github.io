# ExoLand WIKI

Статический многостраничный сайт на HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

## Запуск

Откройте `index.html` в браузере. Для проверки в условиях, близких к публикации, можно запустить любой локальный HTTP-сервер в этой папке.

## Что заполнить перед публикацией

Все неизвестные данные собраны в одном файле — `config.js`:

- `server.address` — IP или домен сервера;
- `server.version` — версия Minecraft;
- `server.access` — формат доступа (свободный вход, whitelist, заявка);
- `server.status` — статус проекта;
- `server.addressPublished` — поставить `true`, когда адрес можно копировать;
- `requiredMod.name` — название обязательного мода;
- `requiredMod.loader` — загрузчик;
- `requiredMod.downloadUrl` — официальная ссылка на скачивание;
- `links.community`, `links.application`, `links.support` — ссылки сообщества.

Пустые ссылки автоматически отображаются как неактивные кнопки. После заполнения `config.js` менять HTML-страницы не требуется.

## Структура

- `index.html` — информация о сервере;
- `join.html` — подключение;
- `required-mod.html` — обязательный мод;
- `recommended-mods.html` — желательные моды;
- `lore.html` — РП и лор;
- `rules.html` — правила;
- `faq.html` — вопросы и ответы;
- `styles.css` — весь внешний вид и адаптивность;
- `script.js` — меню, поиск, фильтры, копирование и общие элементы;
- `config.js` — редактируемые данные проекта;
- `Source/` — исходные изображения.
